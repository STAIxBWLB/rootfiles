This release fixes two misleading controller reports: a false update warning in `rootfiles doctor` and a `fleet init` suggestion from `rootfiles monitor`.

### Fixed
- On a fleet controller, `rootfiles doctor` warned "0.22.1 installed; v0.22.1 available" even on the latest release, so `rootfiles doctor --strict` exited 2. It now reports the version as current. (#197)
- On a fleet controller, `rootfiles monitor` suggested `rootfiles fleet init --inventory <path>` when only a host's `config:` file was missing, a step that backs up and replaces a working inventory. It now shows the load error alone and suggests `fleet init` only when the inventory file itself is missing. (#198)

### Action needed
- Update the fleet controller with `rootfiles update` on macOS, or `sudo rootfiles update` on a Linux controller. Both fixes run only on the controller, so hosts can stay on v0.22.0; to keep versions aligned, run `rootfiles fleet update --all --version v0.22.2 --yes`. (#200)
