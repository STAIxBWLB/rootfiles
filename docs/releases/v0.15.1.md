Files that `rootfiles fleet apply` creates on a host are readable again by non-root users where they should be.

### Fixed
- `rootfiles fleet apply` ran the remote `apply` with a private umask, so files it created were readable only by root. On Ubuntu hosts, the new `/etc/apt/apt.conf.d/zzzzzz-rootfiles-unattended-upgrades` was 0600 and `apt` run as a regular user warned that it could not read it. (#74)

### Action needed
- Update the controller binary that runs `rootfiles fleet`; the hosts do not need an update for this fix. On a host already applied with v0.15.0 through `rootfiles fleet apply`, run `sudo chmod 0644 /etc/apt/apt.conf.d/zzzzzz-rootfiles-unattended-upgrades`. (#74)
