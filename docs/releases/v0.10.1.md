Hosts that self-updated to v0.10.0 now also get the `root` alias.

### Fixed
- `rootfiles update` creates the `root` symlink after updating a binary in `/usr/local/bin` or `/usr/bin`, fixing `root: command not found` on hosts that never re-ran the installer. Custom install locations are left alone.
