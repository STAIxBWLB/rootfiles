Update checks can run without sudo and report available updates with exit 2, while new audit records and backup notes hide command-line credentials.

### Improved

- `rootfiles update --check` (including the `upgrade` alias) and `rootfiles tunnel update --check` run without root or the host lock and exit 0 when current, 2 when an update or missing cloudflared installation is available, and 1 on a lookup error. (#100)

### Fixed

- `apply --tunnel-token`, `tunnel setup TOKEN` and `user passwd --password` no longer expose their token or password in new audit command records or backup-session notes shown by `rootfiles rollback`. Both `--flag value` and `--flag=value` forms are masked. (#100)
