# Command inventory

Generated by `make cli-inventory` from `Inventory` in `internal/cli/inventory.go` and from a colour-off
capture of each report `ReportInventory` marks measured; `go test ./internal/cli -run TestDocsCommandInventory`
fails when this page, the command tree and those captures disagree. Do not edit it by hand.

Widths are measured with the same counter the help pages use, against an 80-column budget; summaries are held to 60 characters so they fit beside the longest command path.

`$HOME`-relative flag defaults are rendered against `/home/operator` so this page is the same on every machine; a width that includes such a default is one char longer or shorter on a host whose home is a different length.

The platform is pinned to `linux`, the host this binary configures: help that differs
between a Linux server and a controller (which flags exist, which report is read) is
recorded here as the server sees it.

## Notes

- Boolean flags print bare (`--ascii`, not `--ascii[=true|false]`). Measured cause: pflag v1.1.0's `FlagUsagesWrapped` appends the hint before it measures the column width, and v1.0.9 (what `dot` pins) does not. Help rendering drops the hint (`withoutBoolValueHint`) rather than pin the dependency back.
- Widths here are the unwrapped help lines. A page over 80 columns is a page a person has to scroll sideways, and the count is the same whatever `COLUMNS` says.
- The inventory cannot tell a verb from a noun, so it records each summary's first word above instead of guessing at the form.
- Report issues are measured from the captured text, so they are a snapshot of this slice: `starts with a blank line` and `no header line` name the reports whose first line is not the `ui.WriteHeader` line. Correcting them is the output slice's work, and the golden it adds is what keeps each family fixed.
- A captured report is measured after the fixture's own absolute path is replaced with `<fixture>`, because a temporary directory's length differs per machine. A host whose home base or state directory is longer than the 80-column budget can still print a wider row than recorded here.
